# Two-Layer Flow Phantom DCS Simulation & Calibration

This repository contains the software simulation pipeline and calibration framework developed to replicate and validate the methodology presented in the research paper:
> **"Deep-learning-based separation of shallow and deep layer blood flow rates in diffuse correlation spectroscopy"** (Nakabayashi et al., 2023, *Biomedical Optics Express*).

The objective is to accurately simulate diffuse correlation spectroscopy (DCS) intensity autocorrelation curves ($g_2(\tau)$) for a two-layer flow phantom (shallow cutaneous layer and deep muscle layer) and calibrate the simulation to match the physical dataset (`Dataset_phantom-intra40.mat`).

---

## 1. Project Accomplishments & Methods

We performed a complete research, simulation, calibration, and validation workflow:

1. **Voxel Grid & Geometry Design**:
   * Modeled the tissue phantom at a $0.5 \text{ mm}$ spatial resolution ($200 \times 100 \times 101$ voxels, matching the physical $100 \times 50 \times 50.5 \text{ mm}$ dimensions).
   * Defined a shallow layer depth of $5.5 \text{ mm}$ ($11 \text{ voxels}$) and deep layer depth of $35.0 \text{ mm}$ ($70 \text{ voxels}$).
2. **High-Statistics Monte Carlo Simulations (MCX)**:
   * Executed a **100-million photon simulation** on the GPU (`NVIDIA GeForce RTX 4050`) using the `pmcx` package.
   * Extracted the partial pathlengths ($L_s$ and $L_d$) traveled by detected photons in both the shallow and deep layers across three source-detector separations (SDS: $1\text{ cm}$, $2\text{ cm}$, and $3\text{ cm}$).
3. **Dynamic Flow Engine & Calibration**:
   * Translated the volumetric flow rates ($FR$) into Brownian diffusion coefficients ($D_B = \text{scale} \times FR \times 10^{-6}\text{ mm}^2/\text{s}$).
   * Fitted the coherence factors ($\beta$) directly from the physical dataset at $\tau \to 0$.
   * Optimized the dynamic scaling factors ($\text{scale}_s, \text{scale}_d$) globally using Nelder-Mead optimization to minimize Root Mean Squared Error (RMSE) against the physical validation curves.
4. **Validation Plotting & Comparative Analysis**:
   * Validated simulated $g_2(\tau)$ curves across all 1540 trials, evaluating overall MAE and RMSE.
   * Investigated the differences between a simplified **Two-Layer Slab Model** and a **Realistic Model** (with acrylic walls and Mylar sheet).

## 2. Key Scientific Findings & Results

### 1. Calibration Parameters
* **Fitted Coherence Factors ($\beta$):**
  * $1\text{ cm}$ SDS: **0.4051**
  * $2\text{ cm}$ SDS: **0.4943**
  * $3\text{ cm}$ SDS: **0.4845**
* **Calibrated Flow Scaling Factors ($\text{scale}_s, \text{scale}_d$):**
  * Shallow layer flow scale ($\text{scale}_s$): **0.0962**
  * Deep layer flow scale ($\text{scale}_d$): **0.5492**

### 2. Geometry Comparison: Slab vs. Realistic Model
* **Finding:** The simplified **Two-Layer Slab Model** matches the physical dataset significantly better than the realistic model.
* **Explanation:** In the realistic grid geometry, the thin $0.05\text{ mm}$ Mylar separator must be modeled as a whole $0.5\text{ mm}$ voxel layer (the resolution limit of the grid). This models it as a thick, highly scattering barrier ($\mu_s = 10\text{ mm}^{-1}$), which physically distorts the photon paths and degrades accuracy. 
* **Recommendation:** Use the two-layer slab model, which represents contiguous scattering media. This matches the authors' own Monte Carlo setup and provides the lowest baseline error.

### 3. Quantitative Curve Comparison Metrics (All 1540 Trials)
After integrating our calibrated scaling factors, the simulation baseline error dropped substantially:
* **1 cm SDS:** MAE improved from **0.09114** to **0.07122** (~22% reduction in error).
* **2 cm SDS:** MAE of **0.09245** / RMSE of **0.16367**.
* **3 cm SDS:** MAE of **0.08961** / RMSE of **0.16392**.

## 4. How to Run the Pipeline

### Prerequisites
Activate the virtual environment containing `pmcx`, `scipy`, `numpy`, and `matplotlib`:
```powershell
.\venv_mcx\Scripts\activate
```

### Dataset Conversion (MAT to CSV)
To convert the MATLAB dataset into CSV format:
```powershell
python .\code\mat_to_csv.py --input .\data\Dataset_phantom-intra40.mat --outdir .\data
```
This produces two CSV files in the `data/` directory:
* `data/Dataset_metadata.csv` (1540 rows, 7 columns): Features/Labels metadata.
* `data/Dataset_flattened.csv` (1540 rows, 1510 columns): Horizontally concatenated metadata and g2 curves.

### Step 1: Run MCX Simulation
Generate the pathlength database (using realistic geometry):
```powershell
python .\code\simulation.py --nphoton 1e8 --geometry realistic --output .\data\pathlengths.npz
```

### Step 2: Generate Simulated Dataset
Generate the simulated MATLAB dataset `Dataset_simulated-intra40.mat` (uses calibrated scaling factors automatically):
```powershell
python .\code\generate_dataset.py --pathlengths .\data\pathlengths.npz --physical-mat .\data\Dataset_phantom-intra40.mat --output .\data\Dataset_simulated-intra40.mat
```

### Step 3: Run Comparison
Evaluate simulated curves against the physical dataset:
```powershell
python .\code\compare.py --physical .\data\Dataset_phantom-intra40.mat --simulated .\data\Dataset_simulated-intra40.mat --output-plot .\plots\g2_comparison.png
```
